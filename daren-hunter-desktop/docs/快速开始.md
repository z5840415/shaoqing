# 达人猎手 - 5分钟快速上手

## 第一步：启动应用

### Windows用户
双击 `start.bat` 文件

### Linux/Mac用户
```bash
./start.sh
```

或者手动启动：
```bash
npm start
```

## 第二步：配置Cookie（必须）

1. **获取Cookie**
   - 在浏览器中打开 https://www.douyin.com
   - 登录你的抖音账号
   - 按 `F12` 打开开发者工具
   - 切换到 `Console`（控制台）标签
   - 输入：`document.cookie` 并回车
   - 复制输出的完整Cookie字符串

2. **保存Cookie**
   - 在应用中点击左侧"设置"
   - 将Cookie粘贴到输入框
   - 点击"保存Cookie"
   - 点击"测试连接"确认有效

## 第三步：准备达人数据

### 方式1：使用模板导入（推荐）

1. 点击"达人管理"
2. 点击"下载模板"
3. 在Excel中填写达人信息：
   ```
   昵称 | 抖音ID | 主页链接 | 粉丝数 | 标签 | 备注
   AI工坊 | xxx123 | https://... | 28000 | AI视频 | 优质作者
   ```
4. 点击"导入Excel"，选择填好的文件

### 方式2：手动添加

1. 在达人管理页面点击单个达人进行编辑
2. 填写必填信息（昵称、抖音ID）
3. 保存

## 第四步：准备话术

应用已经内置了3个默认话术，你可以：

### 使用默认话术
直接使用即可

### 自定义话术
1. 点击"话术库"
2. 点击"新建话术"
3. 填写话术内容，支持变量：
   - `{昵称}` - 达人昵称
   - `{粉丝数}` - 粉丝数量
   - `{微信号}` - 你的微信号
4. 保存并设为默认（可选）

**话术示例：**
```
您好，我是网易旗下永劫无间生态内容的运营，我们每个月针对AI作者有一个扶持计划，每月发布4-10条永劫无间相关内容最多可获得1.5万激励，爆款视频还有额外激励，感兴趣请加我v：your_wechat_id
```

## 第五步：开始发送

1. **选择目标**
   - 在达人管理页面勾选需要发送的达人
   - 点击"批量发送"

2. **配置发送**
   - 选择话术模板
   - 设置发送间隔（推荐30-60秒）
   - 设置每日上限（推荐100条）
   - 确认其他安全设置

3. **启动发送**
   - 点击"开始发送"
   - 实时查看发送进度
   - 可随时暂停或停止

4. **查看结果**
   - 发送完成后会显示统计结果
   - 成功数、失败数、失败原因等

## 第六步：查看数据

### 数据统计
- 点击"数据统计"查看：
  - 今日/本周/本月发送量
  - 回复率
  - 话术效果对比
  - 最佳发送时间

### 导出报表
- 点击"导出报表"下载Excel统计数据

## 安全建议

### ⚠️ 重要提醒

1. **频率控制**
   - 首次使用建议使用"保守模式"
   - 发送间隔设置30-60秒
   - 每日不超过100条

2. **Cookie管理**
   - Cookie有效期约30天
   - 定期检查Cookie状态
   - 失效后及时更新

3. **账号安全**
   - 准备2-3个账号轮换
   - 如遇限流立即停止
   - 适当手动回复消息

4. **合规使用**
   - 遵守平台规则
   - 内容合法合规
   - 不过度骚扰用户

## 常见问题速查

| 问题 | 解决方案 |
|------|---------|
| Cookie失效 | 重新获取并保存Cookie |
| 发送失败 | 检查网络、降低频率、更新Cookie |
| 没有回复 | 优化话术、选择最佳时间发送 |
| 应用闪退 | 查看错误日志、重启应用 |
| 数据丢失 | 数据保存在本地数据库，重启恢复 |

## 进阶使用

### 1. 批量操作
- 支持勾选多个达人进行批量发送
- 支持批量删除
- 支持批量导出

### 2. 状态管理
- 手动标记达人状态（已回复、已加微信、已签约等）
- 按状态筛选达人
- 跟踪转化漏斗

### 3. A/B测试
- 创建多个话术版本
- 对比不同话术的回复率
- 选择最优话术

### 4. 定时发送
- 选择最佳时间段发送
- 设置定时任务
- 自动化运营

## 数据导出

### 导出达人列表
1. 选择需要导出的达人（或全部）
2. 点击"导出"
3. 保存Excel文件

### 导出统计报表
1. 进入"数据统计"
2. 点击"导出报表"
3. 获得包含多个统计维度的Excel文件
