# 达人猎手 - 开发指南

## 技术栈详解

### 前端技术

- **Electron**: 跨平台桌面应用框架
- **HTML/CSS/JavaScript**: 纯前端技术，无框架依赖
- **架构模式**: MVC模式，页面分离

### 后端技术

- **FastAPI**: 现代Python Web框架
- **SQLAlchemy**: ORM数据库操作
- **Playwright**: 浏览器自动化
- **Uvicorn**: ASGI服务器

## 项目架构

### 前后端分离

```
┌─────────────┐         HTTP API         ┌─────────────┐
│   Electron  │ ◄─────────────────────► │   FastAPI   │
│   (前端UI)   │                          │   (后端服务)  │
└─────────────┘                          └─────────────┘
                                               │
                                               ▼
                                         ┌──────────┐
                                         │  SQLite  │
                                         │  (数据库)  │
                                         └──────────┘
                                               │
                                               ▼
                                         ┌──────────┐
                                         │Playwright│
                                         │(自动化)   │
                                         └──────────┘
```

### 数据流

1. **用户操作** → 前端界面
2. **前端** → HTTP请求 → 后端API
3. **后端** → 处理业务逻辑 → 数据库操作
4. **后端** → 调用Playwright → 抖音自动化
5. **后端** → 返回结果 → 前端
6. **前端** → 更新UI显示

## 核心模块详解

### 1. 数据库设计

#### targets表（达人信息）
```sql
CREATE TABLE targets (
    id INTEGER PRIMARY KEY,
    nickname VARCHAR(100) NOT NULL,
    douyin_id VARCHAR(100) UNIQUE NOT NULL,
    homepage_url VARCHAR(500),
    fans_count INTEGER DEFAULT 0,
    tags VARCHAR(200),
    status VARCHAR(50) DEFAULT 'pending',
    notes TEXT,
    created_at DATETIME,
    updated_at DATETIME

```

#### templates表（话术模板）
```sql
CREATE TABLE templates (
    id INTEGER PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    content TEXT NOT NULL,
    is_default BOOLEAN DEFAULT FALSE,
    usage_count INTEGER DEFAULT 0,
    reply_count INTEGER DEFAULT 0,
    created_at DATETIME,
    updated_at DATETIME
);
```

#### send_logs表（发送记录）
```sql
CREATE TABLE send_logs (
    id INTEGER PRIMARY KEY,
    target_id INTEGER NOT NULL,
    target_nickname VARCHAR(100),
    template_id INTEGER,
    template_name VARCHAR(100),
    message_content TEXT,
    status VARCHAR(50),
    error_message TEXT,
    reply_status VARCHAR(50) DEFAULT 'waiting',
    reply_content TEXT,
    send_time DATETIME,
    reply_time DATETIME,
    created_at DATETIME
);
```

### 2. API端点设计

#### 达人管理
- `GET /api/targets/` - 获取达人列表
- `POST /api/targets/` - 创建达人
- `PUT /api/targets/{id}` - 更新达人
- `DELETE /api/targets/{id}` - 删除达人
- `POST /api/targets/import-excel` - 导入Excel
- `GET /api/targets/download/template` - 下载模板

#### 话术管理
- `GET /api/templates/` - 获取话术列表
- `POST /api/templates/` - 创建话术

- `DELETE /api/templates/{id}` - 删除话术
- `POST /api/templates/{id}/set-default` - 设为默认

#### 发送任务
- `POST /api/send/start` - 启动发送
- `GET /api/send/progress` - 获取进度
- `POST /api/send/pause` - 暂停发送
- `POST /api/send/resume` - 恢复发送
- `POST /api/send/stop` - 停止发送

- `GET /api/statistics/overview` - 数据概览
- `GET /api/statistics/templates` - 话术统计

#### 设置管理
- `GET /api/settings/cookie/get` - 获取Cookie
- `POST /api/settings/cookie/save` - 保存Cookie
- `POST /api/settings/cookie/test` - 测试Cookie
- `GET /api/settings/security/get` - 获取安全配置
- `POST /api/settings/security/save` - 保存安全配置

### 3. Playwright自动化

#### 核心流程

```python
# 1. 初始化浏览器
playwright = await async_playwright().start()
browser = await playwright.chromium.launch(headless=True)

# 2. 创建上下文并加载Cookie
context = await browser.new_context()
await context.add_cookies(cookies)

# 3. 访问目标主页
page = await context.new_page()
await page.goto(homepage_url)

# 4. 查找并点击私信按钮
message_button = await page.wait_for_selector('text="私信"')
await message_button.click()

# 5. 输入消息
input_box = await page.wait_for_selector('textarea[placeholder*="消息"]')
await input_box.type(message, delay=100)  # 模拟打字

# 6. 发送
send_button = await page.wait_for_selector('button:has-text("发送")')
await send_button.click()
```

#### 安全机制

1. **随机间隔**
```python
import random
interval = random.uniform(min_interval, max_interval)
await asyncio.sleep(interval)
```

2. **批次休息**
```python
if count % batch_size == 0:
    await asyncio.sleep(batch_rest)
```

3. **行为模拟**
```python
# 访问主页停留
await page.goto(homepage_url)
await asyncio.sleep(random.uniform(2, 5))

# 模拟滚动
await page.evaluate("window.scrollBy(0, Math.random() * 500)")

# 模拟打字
for char in message:
    await input_box.type(char)
    await asyncio.sleep(random.uniform(0.05, 0.15))
```

## 常见问题解决

### Q1: Playwright浏览器无法启动

**解决方案:**
```bash
playwright install chromium
```

### Q2: CORS跨域错误

**解决方案:**
确保FastAPI配置了CORS中间件
```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### Q3: Electron打包后Python无法运行

**解决方案:**
使用PyInstaller打包Python程序，并在Electron中正确引用

### Q4: 数据库锁定错误

**解决方案:**
使用连接池或确保及时关闭数据库连接
```python
finally:
    db.close()
```
