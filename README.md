# 逃离鸭科夫 (Escape from Duckoff)

一个使用纯HTML5 Canvas和JavaScript开发的2D俯视角生存射击游戏。

## 🎮 游戏简介

你扮演一只鸭子，被困在危险的鸭科夫地区。你需要：
- 收集医疗包和弹药
- 击败敌对的鸭子
- 找到撤离点
- 在5分钟时间耗尽前成功逃离！

## 🚀 如何运行

1. 直接在浏览器中打开 `escape-from-duckoff.html` 文件
2. 无需任何外部依赖或服务器
3. 推荐使用Chrome、Firefox或Edge浏览器

```bash
# 方法1: 直接双击文件
escape-from-duckoff.html

# 方法2: 使用浏览器打开
firefox escape-from-duckoff.html
# 或
google-chrome escape-from-duckoff.html
```

## 🎯 游戏操作

| 按键 | 功能 |
|------|------|
| W/A/S/D | 移动 |
| 鼠标移动 | 瞄准 |
| 鼠标左键 | 射击 |
| E | 拾取物品 / 撤离 |
| ESC | 暂停游戏 |
| 空格 | 开始游戏 |

## 🦆 敌人类型

### 巡逻鸭 (红色)
- 血量: 50
- 速度: 中等
- 行为: 发现玩家后追击

### 狙击鸭 (紫色)
- 血量: 30
- 速度: 较慢
- 行为: 远距离攻击，射程远

### 冲锋鸭 (深红色)
- 血量: 80
- 速度: 很快
- 行为: 快速冲向玩家近战

## 📦 物品系统

- **医疗包** (绿色圆圈): 恢复50点生命值
- **弹药箱** (橙色圆圈): 补充30发弹药
- **宝箱** (金色方块): 获得100分

## 🏆 胜利条件

找到撤离点（地图边缘的绿色闪烁区域）并按E键撤离

## ❌ 失败条件

- 生命值降为0
- 5分钟倒计时结束

## 💡 游戏提示

1. 优先收集弹药和医疗包
2. 保持移动，避免被围攻
3. 利用障碍物掩护
4. 注意屏幕右上角的敌人数量
5. 低血量时及时寻找医疗包
6. 撤离点在地图边缘，提前规划路线
