# ⚡ 闪购倒计时提醒工具

一款专为秒杀活动设计的桌面倒计时提醒工具，帮助您不错过每一个重要的秒杀时刻！

## ✨ 功能特点

### 🎯 核心功能
- **实时倒计时**：精确显示距离下一个秒杀还有多少分钟和秒数
- **智能提醒**：提前1分钟开始红色闪烁提醒，持续10秒
- **时间表管理**：支持添加、编辑、删除秒杀时间
- **窗口置顶**：始终保持在最前面，不会被其他窗口遮挡
- **全屏模式**：支持全屏显示，适合大屏幕使用
- **自动保存**：所有设置自动保存，下次启动无需重新配置

### 🔔 闪烁提醒规则
- **触发时间**：提前1分钟（60秒前）
- **持续时长**：10秒
- **闪烁频率**：每秒闪烁1次（0.5秒亮，0.5秒灭）
- **智能防重复**：每个秒杀只闪烁一次，不会重复提醒

## 🚀 快速开始

### 环境要求
- Python 3.6 或更高版本
- Tkinter（Python自带，无需额外安装）

### 安装步骤

1. **克隆或下载项目**
   ```bash
   git clone <repository-url>
   cd flash-sale-countdown
   ```

2. **运行程序**
   ```bash
   python flash_sale_countdown.py
   ```

   或者在Windows上双击运行：
   ```bash
   python.exe flash_sale_countdown.py
   ```

### 首次运行
首次运行时，程序会自动创建默认的秒杀时间表（12:20 - 15:40），包含以下时间：
- 12:20, 12:40
- 13:00, 13:20, 13:40
- 14:00, 14:20, 14:40
- 15:00, 15:20, 15:40

### 主界面介绍

```

├─────────────────────────────────────┤
```

### 基本操作

#### 1️⃣ 添加秒杀时间
1. 点击 **"➕ 添加时间"** 按钮
2. 在弹出的对话框中输入时间（格式：HH:MM，如 14:30）
3. 点击 **"确定"** 完成添加

#### 2️⃣ 编辑秒杀时间
1. 在时间表中选中要编辑的时间
2. 点击 **"✏️ 编辑选中"** 按钮
3. 修改时间后点击 **"确定"**

#### 3️⃣ 删除秒杀时间
1. 在时间表中选中要删除的时间（可多选）
2. 点击 **"❌ 删除选中"** 按钮
3. 确认删除

#### 4️⃣ 窗口置顶
- 勾选 **"📌 窗口置顶"** 复选框，窗口将始终保持在最前面
- 取消勾选则允许其他窗口遮挡

#### 5️⃣ 全屏模式
- 点击 **"🖥️ 全屏 (F11)"** 按钮或按 **F11** 键进入全屏
- 按 **ESC** 键或再次按 **F11** 退出全屏

### 快捷键
- **F11**：切换全屏模式
- **ESC**：退出全屏模式
- **Enter**：在输入对话框中确认输入

## 🎨 界面说明

### 状态显示
- **已过期**：当前时间已过的秒杀（灰色文字）
- **还有 X 分钟**：距离秒杀还有多少分钟（普通显示）
- **⚡ 即将开始**：1分钟内即将开始的秒杀（红色闪烁）

### 颜色含义
- **蓝色**：正常倒计时状态
- **红色闪烁**：提醒状态（距离秒杀不到1分钟）
- **灰色**：已过期的秒杀时间

## ❓ 常见问题

### Q1: 为什么闪烁没有触发？
A: 请检查：
1. 秒杀时间是否已经过期
2. 是否距离秒杀还有超过1分钟
3. 该秒杀是否已经闪烁过（每个只闪烁一次）

### Q2: 如何修改默认时间表？
A: 两种方法：
1. 使用界面的添加/编辑/删除功能
2. 直接编辑 `flash_sales.json` 文件（建议备份）

### Q3: 程序可以后台运行吗？
A: 可以最小化到任务栏，但建议保持窗口可见以便看到闪烁提醒

### Q4: 如何打包成exe文件？
A: 使用 PyInstaller：
```bash
pip install pyinstaller
pyinstaller --onefile --windowed flash_sale_countdown.py
```

生成的exe文件在 `dist` 目录中。
